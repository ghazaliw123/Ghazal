# پروژۀ شبیه‌سازی حملۀ DDoS

## معرفی پروژه

این پروژه یک شبیه‌سازی علمی از حملۀ **DDoS (Distributed Denial of Service)** است که برای منظور آموزشی و تحقیقی طراحی شده است.

### اهداف پروژه:
1. درک مکانیسم حملات سایبری (DDoS)
2. اندازه‌گیری تأثیر حمله بر عملکرد سرور
3. بررسی مصرف منابع (CPU و حافظه) قبل و بعد از حمله
4. ارائۀ نتایج به صورت نمودار بصری

---

## تفاوت DOS و DDoS

### حمله DOS (Denial of Service)
- **منبع**: یک کامپیوتر/IP
- **دامنه**: محدود
- **شناسایی**: آسان (از یک IP)

### حمله DDoS (Distributed Denial of Service)
- **منبع**: چندین کامپیوتر/IP متفاوت
- **دامنه**: گسترده
- **شناسایی**: دشوار (از IP های متعدد)

**این پروژه شبیه‌سازی DDoS است** و از **نماینده‌های متعدد** استفاده می‌کند.

---

## معماری پروژه

پروژه از سه بخش اصلی تشکیل شده است:

### 1️⃣ سرور (Server)
- قبول درخواست‌های HTTP
- پاسخ دادن به درخواست‌ها
- اندازه‌گیری CPU و حافظه به صورت مستمر
- ذخیره اطلاعات برای تجزیه و تحلیل بعدی

### 2️⃣ حمله (DDoS Attack)
- ایجاد چندین نخ (Thread) هم‌زمان
- ارسال درخواست‌های HTTP از طریق نماینده‌های متعدد
- شبیه‌سازی حمله از IP های مختلف
- شمارش تعداد درخواست‌های ارسال شده

### 3️⃣ تجزیه و تحلیل (Analysis)
- بارگذاری داده‌های جمع‌آوری شده
- رسم نمودارهای CPU و حافظه
- مقایسۀ وضعیت قبل، حین و بعد از حمله

## فایل‌های پروژه

### 📄 `server.py` - سرور
سرور HTTP که درخواست‌ها را قبول می‌کند و CPU/حافظه را اندازه‌گیری می‌کند.

### 🔴 `ddos_attack.py` - حمله
برنامۀ حمله DDoS با استفاده از نماینده‌های متعدد.

### 📊 `plot_metrics.py` - تجزیه و تحلیل
رسم نمودارهای CPU و حافظه قبل و بعد از حمله.
